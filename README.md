Software and data accompanying the paper "AFT Neural Function Approximators for 1D Nonlinear Force Laws"

The code accompanying the manuscript is currently being prepared for public release and will be made available in this repository in the near future.  
In the meantime, please feel free to contact the corresponding author with any questions regarding the implementation or the methods presented in the manuscript.
